Introduction to Computer Vision

Complete Beginner-to-Intermediate Lecture Notes

1. What is Computer Vision?

```
Computer Vision (CV) is a branch of Artificial Intelligence that enables computers to understand, analyze, and interpret visual information such as images, videos, and camera streams.

Humans use their eyes and brain to understand the world around them. Computer vision attempts to provide computers with a similar ability by processing visual data using mathematics, image processing, machine learning, and deep learning.

``` Human Vision Eyes → Visual Information → Brain → Understanding Computer Vision Camera → Image/Video → Computer Vision Algorithm → Understanding
```

A computer does not see an image in the same way that a human does. It receives an image as numerical data represented by pixels.

```

2. How Does a Computer See an Image?

```

A digital image is composed of small elements called pixels. Each pixel contains numerical information representing the intensity or color at a particular location.

Grayscale Image

A grayscale image normally contains intensity values from 0 to 255.

  • 0 = Black
  • 255 = White
  • Values between 0 and 255 = Shades of gray
```

10   20   30   40
20   50   80   60
30   90  120   70
40   70  100   50
```

Color Image

A common color representation is RGB.

  • R = Red
  • G = Green
  • B = Blue
``` RGB Image Height × Width × 3 Example: 640 × 480 × 3

3. Image as a Matrix

```

Computer vision uses mathematics extensively. Images can be represented as matrices or multidimensional arrays. 

    Width
 ┌─────────────┐
 │ 10  20  30  │
 │ 20  50  80  │
 │ 30  90 120  │
 └─────────────┘
    Height

A grayscale image can be represented using a 2D matrix. An RGB image can be represented using a 3D array.

Example: Python libraries such as NumPy represent images as arrays. This makes mathematical operations on images efficient.
```

4. Computer Vision Pipeline

```

A typical computer vision project follows several stages.

``` Problem Definition ↓ Dataset Collection ↓ Data Preprocessing ↓ Data Visualization ↓ Data Annotation ↓ Dataset Splitting ↓ Model Selection ↓ Model Training ↓ Model Evaluation ↓ Inference ↓ Deployment ↓ Monitoring

5. Dataset Collection

```

The first practical step in many computer vision projects is collecting suitable images or videos.

Possible Data Sources

  • Digital cameras
  • CCTV cameras
  • Drones
  • Mobile phones
  • Satellite imagery
  • Public datasets
  • Industrial cameras
  • Medical imaging devices
  • Robotic cameras

Example: Bolt Detection

Suppose we want to develop an AI system that detects bolts. We may collect thousands of images: 

```

bolt_001.jpg
bolt_002.jpg
bolt_003.jpg
...
bolt_5000.jpg
```

The dataset should represent real-world conditions.

  • Different lighting conditions
  • Different backgrounds
  • Different camera angles
  • Different object sizes
  • Different distances
  • Object rotation
  • Occlusion
  • Blur
  • Noise
```

6. Data Preprocessing

```

Raw image data may not be suitable for direct use. Preprocessing prepares the dataset for analysis and model training.

Common Preprocessing Operations

  • Image resizing
  • Normalization
  • Noise reduction
  • Brightness adjustment
  • Contrast enhancement
  • Image sharpening
  • Color conversion
  • Cropping

Image Resizing

``` 1920 × 1080 ↓ 640 × 640
```

Normalization

Pixel values commonly range from 0 to 255. They can be converted to the range 0 to 1: 

```

normalized_pixel = pixel / 255

7. Data Visualization

```

Visualization helps us understand the dataset before training a model.

Questions Visualization Can Answer

  • How many images are available?
  • How many classes exist?
  • Are some classes underrepresented?
  • Are images too dark or too bright?
  • Are there duplicate images?
  • Are annotations correct?
  • Are objects too small?
Example: If Class A has 5,000 images but Class C has only 800 images, the dataset may suffer from class imbalance.
```

Classification Annotation

Object Detection Annotation

Objects are labeled using bounding boxes. 

```

Segmentation Annotation

Segmentation identifies the pixels belonging to an object.

11. Object Detection

```

Object detection identifies objects and determines their locations inside an image.

``` Input Image ↓ Object Detection Model ↓ Object Class + Bounding Box + Confidence
```

Popular Object Detection Models

  • YOLO
  • Faster R-CNN
  • RetinaNet
  • SSD

YOLO is widely used for real-time object detection.

```

12. Image Segmentation

```

Segmentation works at the pixel level.

Semantic Segmentation

Each pixel is assigned to a class. 

```

Road
Car
Person
Building
Sky
```

Instance Segmentation

Different objects belonging to the same class are separated. 

```

Person 1 → Mask 1
Person 2 → Mask 2
Person 3 → Mask 3
```

Popular Segmentation Architectures

  • U-Net
  • Mask R-CNN
  • YOLO Segmentation
  • DeepLab
```

13. Object Tracking

```

Object tracking follows an object across multiple video frames.

``` Frame 1 → Car ID 1 Frame 2 → Car ID 1 Frame 3 → Car ID 1 Frame 4 → Car ID 1
```

Applications include:

  • Traffic monitoring
  • People counting
  • Sports analytics
  • Surveillance
  • Robotics
  • Drone tracking
```

Face Recognition

OCR converts text contained in images into machine-readable text.

Example: An invoice image containing "Invoice No: 12345" can be processed to extract the same text digitally.

Applications

  • Invoices
  • Receipts

  • Number plates
  • ID cards

```

16. Traditional Computer Vision

```

Before deep learning became dominant, computer vision systems relied heavily on manually designed image-processing algorithms.

Important Techniques

  • Edge Detection
  • Thresholding
  • Contours
  • Morphological Operations
  • HOG
  • SIFT
  • ORB

Edge Detection

Edge detection identifies boundaries or sudden changes in image intensity.

One popular algorithm is Canny Edge Detection.

Thresholding

Thresholding separates regions based on pixel intensity.

``` Grayscale Image ↓ Threshold ↓ Binary Image ↓ Black / White Regions
```

Contours

Contours represent object boundaries and are useful for shape analysis, object measurement, and simple object detection.

```

17. Deep Learning in Computer Vision

```

Modern computer vision heavily relies on deep learning.

One of the most important deep learning architectures for computer vision is the Convolutional Neural Network (CNN).

``` Input Image ↓ Convolution ↓ Feature Maps ↓ Activation ↓ Pooling ↓ More Convolution ↓ High-Level Features ↓ Prediction

18. Convolutional Neural Networks

```

CNNs learn visual features automatically from training data.

Early Layers

  • Edges
  • Lines
  • Simple patterns

Middle Layers

  • Shapes
  • Textures
  • Corners

Later Layers

  • Faces
  • Wheels
  • Objects
  • Complex visual patterns
```

19. What is Convolution?

```

Convolution uses a small matrix called a kernel or filter. The filter moves across the image and performs mathematical operations. 

```

Example Kernel:

1   0  -1
1   0  -1
1   0  -1
```

Different filters can detect different patterns such as vertical edges, horizontal edges, corners, and textures.

In a CNN, these filters are learned automatically during training.

```

20. Transfer Learning

```

Training a large computer vision model from scratch can require large datasets and significant computational resources.

Transfer learning allows us to start with a model that has already learned useful visual features.

``` Pretrained Model ↓ Learned Features ↓ Your Dataset ↓ Fine-Tuning ↓ Custom Vision Model
```

Transfer learning is especially useful when your custom dataset is relatively small.

```

21. Data Augmentation

```

Data augmentation creates modified versions of existing images. This helps expose the model to different visual conditions.

Common Augmentations

  • Rotation
  • Horizontal flipping
  • Vertical flipping
  • Cropping
  • Zooming
  • Brightness adjustment
  • Contrast adjustment
  • Blur
  • Noise
  • Perspective transformation
Augmentation should represent realistic variations that may occur in the real application.
```

Dataset Purpose

Classification Metrics

Object Detection Metrics

Segmentation Metrics

```

24. Intersection over Union — IoU

```

IoU measures how much the predicted region overlaps with the ground-truth region. 

```

IoU = Intersection Area / Union Area
```

A higher IoU generally indicates better overlap between prediction and ground truth.

```

25. Precision and Recall

```

Precision

Precision answers: Of everything predicted as positive, how much was actually positive?

Recall

Recall answers: Of everything that was actually positive, how much did the model find?

In a defect detection system, high recall may be important because missing a defective product could be costly.
```

26. Computer Vision Inference

```

Inference is the process of using a trained model to make predictions on new images or videos.

``` Camera ↓ Image ↓ Preprocessing ↓ Trained Model ↓ Inference ↓ Prediction

27. Real-Time Computer Vision

```

Real-time computer vision processes camera or video frames continuously.

``` Camera ↓ Frame 1 → Detection Frame 2 → Detection Frame 3 → Detection Frame 4 → Detection ...
```

FPS — Frames Per Second

FPS indicates how many frames a system can process per second.

  • 10 FPS
  • 30 FPS
  • 60 FPS

Higher FPS generally means faster processing, but latency, accuracy, hardware capability, and model complexity must also be considered.

```
